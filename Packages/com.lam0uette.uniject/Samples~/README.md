# Samples

Six samples land here, each teaching exactly one thing, each at most 120 lines, each with a
one-paragraph README:

1. **Hello** — one binding, one injected field.
2. **Installers** — several installers, order-independent.
3. **GameObjects & prefabs** — sources and placement verbs.
4. **Conditional bindings** — ids and `When*` conditions.
5. **Factories** — `BindFactory` and `PlaceholderFactory`.
6. **Lifecycle** — `IInitializable`, `ITickable`, disposal order.

They are registered in `package.json` under `samples` once written. The folder ends with `~` so
Unity does not compile it in the development project.
